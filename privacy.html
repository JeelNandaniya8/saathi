Privacy

Your information should stay understandable and controllable.

This page explains what Saathi stores and which outside services process information. It avoids promises that no online service can honestly make.

Saathi is still being prepared for public launch. Do not store information you would not be comfortable keeping in an online account.

Information Saathi stores

  • Account details such as name, username, email, password hash, selected language and plan status.
  • Conversations, messages, the selected AI response mode and photos or PDFs attached to a message.
  • Tasks, reminders, habits, check-ins, journal entries and memories you choose to save.
  • Trusted-contact or Family features only after the required consent is provided.
  • Limited security records used to prevent repeated login, signup and reset attempts.

Passwords are stored as hashes. Saathi should never ask you to send a password or verification code in a chat message.

Services that process information

Google Gemini

The Saathi server sends selected recent chat context, active memories and any photo or PDF attached to the current request to Google Gemini to prepare a reply. The browser does not receive the Gemini API key. Saathi may store provider-reported token counts, selected mode and attachment count to understand operating cost. This usage record does not make an extra copy of message or file content.

Brevo

Brevo processes the recipient name, email address and email content needed for verification, password reset and any separately enabled email delivery.

PostgreSQL hosting

The configured PostgreSQL provider stores account, workspace and attachment records. Hosting providers may process normal service logs needed to operate the application.

Private workspace boundaries

Journal entries, conversations, memories and check-ins belong to the signed-in account. Family features must not reveal private chats, journals, check-ins or memories to another person. A user must explicitly choose what to share.

Memory controls

Only memories the user saves are included in future Gemini context. Memories can be paused or deleted from the dashboard. Saathi does not claim to remember information outside the visible saved-memory list.

Reminders and notifications

Reminder titles, notes, schedules and delivery status may be stored. Browser notification permission is controlled by the device. Sensitive details should be kept out of lock-screen notifications where possible.

Export, deletion and retention

A signed-in user can export account data and permanently delete the account. JSON exports list attachment metadata and signed-in download links; attachment files can be opened separately while the account exists. Deleting a message, conversation or account also deletes its active attachment records. Deleted data may remain temporarily in infrastructure backups before normal backup expiry.

Contact and changes

Use the support form for privacy questions. Important policy changes should be shown clearly with an updated date.
